# Ronak Harkhani — Portfolio

Personal homepage and developer portfolio published with GitHub Pages.

## Project context

- **Primary goal:** Help potential employers, friends, and GitHub visitors learn about Ronak.
- **Public identity:** Ronak Harkhani, Android Engineer at PhonePe, Bengaluru, India.
- **Tone:** Friendly and human while remaining professional.
- **Visual direction:** Clean, minimal, dark, sharp corners, thin lines, and restrained blue/green accents. Avoid terminal styling and unnecessary animation for now.
- **Implementation:** Plain HTML and CSS with no framework, JavaScript, analytics, or build step.
