# Ronak Harkhani — Portfolio

My personal homepage and developer portfolio, featuring the apps and developer tools I build alongside my experience and interests.

**Live site:** [axondragonscale.github.io](https://axondragonscale.github.io/)

## Built with

- Semantic HTML
- Responsive CSS
- GitHub Pages

There is no framework, JavaScript, package manager, or build step.

## Run locally

Open `index.html` directly, or serve the repository root:

```sh
python3 -m http.server 8000
```

Then visit [localhost:8000](http://localhost:8000).
